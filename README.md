# 你就是我的宇宙 · 云端相册版

赵管家 × 黄少爷，始于北京时间 2026 年 6 月 24 日。当天算在一起的第 1 天，此后每天零点加一天，不按确认时刻起算。

保留星空、照片墙、相恋时钟、故事、愿望与小游戏。照片、故事、愿望和情书存于 Supabase 私有云，支持两位成员登录后跨设备查看。

## 使用

页首「写封情书」可编辑你们共同的情书；以前的情书版本可在编辑框内查看并重新使用。背景音乐使用用户提供的《我曾这样寂寞生活》，点击音乐按钮播放或暂停，切到后台时暂停。

首次使用专属的一次性开通链接，由本人设置至少 12 个字符的相册密码。以后用邮箱与该密码登录「共享相册」。开通链接只存于私有交付目录，不属于网站源码。

登录后上传照片，照片和标题、分类、日期都保存到云端。另一设备登录后打开或刷新即可读取；当前打开的页面每 30 秒同步一次，切回页面时也会刷新。

使用相册账号登录后，新增的故事、愿望、愿望状态与情书也同步到私有云。另一设备登录后打开、刷新页面或等待下一次同步即可看到。退出后，页面不再显示云端的私密回忆。

首次登录同步时，网站会合并当前设备、当前浏览器里原有的故事和愿望，并私密备份原始内容，不删除本地记录。若旧情书与已修改的共享情书不同，旧信会保存在「查看以前的情书」中，不覆盖共享版本；旧愿望状态有冲突时会显示本机原状态供核对。其他设备或浏览器中的旧内容，需要在对应设备和浏览器打开网站并登录，才能各自迁移。

照片墙每页最多展示 12 张，使用「上一页 / 下一页」翻页。分类筛选从第 1 页开始，刷新同步保留当前页；删除最后一页的末张照片后自动回到仍有照片的页面。照片大图可以继续浏览同一分类中的全部照片。

网站不设照片总数量上限，上传和从回收站恢复都不受原来的 60 张限制。云端按批次读取全部照片，避免接口单次返回数量造成截断；签名链接分批生成并在有效期内复用。实际可存储总量仍取决于 Supabase 套餐容量。单次上传最多 12 张，单张原文件最多 20 MB，上传时自动压缩。

点开自己上传的照片，在大图下方点「删除照片」，确认后移入回收站；照片墙旁的「回收站」可以恢复。仅上传者可以删除、查看自己的回收站列表和恢复照片。删除、恢复在其他设备下一次同步时生效。回收站保留私有原图，不自动清空、不释放存储空间；已经导出的离线文件不受云端删除影响。移入回收站不撤销相册成员对已知原图路径的访问权限，之前生成的签名链接最多一小时后失效。

当前只开放用户指定的账号。第二个账号需要在后台名单中加入，且使用独立开通链接自行设置密码。数据库最多允许一个 owner 和一个 partner。前台没有公开注册入口。

## 数据边界

- 相册照片、分类、标题、日期：云端共享。
- 故事、愿望、情书及其历史版本：同一成员名单下私密云端共享；旧浏览器内容在对应浏览器登录后迁移。
- 退出后立即清除页面中的私密照片和回忆展示；其他设备的登录不受影响。
- GitHub Pages 的网页展示范围由 GitHub 配置决定，当前页面的预置文案在静态源码中。私密照片始终通过云端鉴权，不放进代码仓库。

## 后端

项目：`our-universe`，区域：Singapore，项目引用：`ktjtnwduryzxrbptgiuk`。

- 数据表：`public.album_photos`，RLS 对名单内的已登录账号开放。
- 共同回忆数据表：`public.universe_stories`、`universe_wishes`、`universe_letter`、`universe_letter_history`、`universe_legacy_backups`，RLS 复用同一成员名单。
- 私有桶：`our-universe-private`，原图使用短时签名链接。
- 成员名单：`private.album_members`，账号只能读取自己的角色，无法在网页修改成员。
- 开通能力：`album-enroll` Edge Function，校验高熵的一次性开通令牌；数据库只保存令牌哈希，绑定预先授权的邮箱。
- 管理服务密钥由 Supabase 托管在函数环境中；前端只使用 publishable key。
- SQL 迁移文件在 `supabase/migrations/`。

## 本地检查

```powershell
node scripts/verify.cjs
node scripts/check-shared-memories.cjs
python scripts/cloud-access-check.py
python -m http.server 4175 --bind 127.0.0.1 --directory dist
```

`scripts/preview-private.py` 仅供本机开通时使用，需有被 Git 忽略的 `.private/enrollment.json`。不要把 `.private/` 上传到仓库。

Supabase JavaScript SDK 版本固定为 `2.118.0`，官方 npm 包的 UMD 文件自托管在 `dist/vendor/`，不需要第三方 CDN 才能加载页面。
